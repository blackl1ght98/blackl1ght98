## ⭐ Proyecto Estrella

<div align="center">
  <h3>📦 Gestor de Inventario Empresarial</h3>
  <p><em>Sistema de gestión de inventario Full Stack diseñado con arquitectura limpia, alta disponibilidad y escalabilidad.</em></p>
</div>

#### 📌 Características Principales
- **Autenticación & Seguridad:** Control de acceso mediante **JWT** y gestión segura de roles.
- **Rendimiento:** Caché distribuida integrada con **Redis** para optimizar consultas frecuentes.
- **Pagos & Facturación:** Integración completa con pasarela de pago (**PayPal API**).
- **Despliegue & Contenedores:** Entorno totalmente orquestado y listo para producción mediante **Docker**.
